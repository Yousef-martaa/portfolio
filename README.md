This portfolio demonstrates practical use of frontend and backend fundamentals, including client–server communication, clean layout structure, and version control with Git.

- JavaScript (ES6)
- Node.js
- Express
- REST-style API
- Git & GitHub

- Express server serving static frontend files
- Simple API endpoint for projects data
